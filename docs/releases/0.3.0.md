# Vestel Smart Life 0.3.0

English | [Türkçe](#türkçe)

This release adds English/Turkish interface translations, improves startup and command confirmation, strengthens diagnostic redaction, and clarifies installation and source attribution.

## Read before upgrading

**Some automation values change.** Select options, enum sensor states and climate fan modes now use stable machine tokens. Home Assistant translates their visible labels into English or Turkish.

| Previous literal value | New machine token |
| --- | --- |
| `Ekonomi` | `eco` |
| `Pamuklu` | `cotton` |
| `Soğutma` (enum sensor/option) | `cooling` |
| `Auto` (climate fan mode) | `auto` |

Review literal values in automations, scripts, templates and dashboards before relying on them after the upgrade. Inspect actual states/options in Developer Tools rather than copying display labels. Existing history can contain both old text and new tokens. Advanced `vestel_appliances.apply` values remain vendor-defined integers; do not replace them with these tokens.

Back up Home Assistant, update through HACS, and follow its restart prompt. Keep your existing `vestel_appliances` config entry. Existing entity IDs and unique IDs are preserved; custom integration entry titles are retained. The displayed default name is now **Vestel Smart Life**.

The repository is now [halilyildiz/vestel-smart-life-home-assistant](https://github.com/halilyildiz/vestel-smart-life-home-assistant). GitHub redirects the old repository address; do not delete your integration entry merely because the repository was renamed. The minimum Home Assistant version remains **2026.11.0**.

Read the [migration guide](https://github.com/halilyildiz/vestel-smart-life-home-assistant/blob/main/docs/upgrading.md), including the separate setup required when coming from Mehmet Aktaş's `vestel_smarthome` integration.

## Improvements

- English source strings and Turkish translations for controls, status labels, services, selectors and user-facing errors.
- Appliance controls and live updates start without waiting for optional energy history; the initial background fetch is cancelled on unload.
- Shared-register readback checks the targeted fields, so unrelated changes do not prevent confirmation. Existing UV and cancellation checks remain in place.
- Temporary authentication-server failures and rate limits no longer incorrectly request reauthentication. Malformed responses are rejected before cached credentials are changed.
- Diagnostics export selected technical metadata and better mask nested/repeated private values. Inspect downloaded diagnostics before sharing them.
- Simpler bilingual READMEs with separate installation-related guides, advanced examples, migration instructions and security reporting details.
- Explicit attribution to [Mehmet Aktaş's original MIT-licensed project](https://github.com/mehmetaktas/ha-vestel-smarthome), with both complete MIT notices included in the installation folder.
- Checkout/setup-python actions use Node.js 24 runtimes.

## Validation and scope

The current offline suite has **155 passing tests**. GitHub Actions runs the offline tests, hassfest and HACS validation. The offline suite mostly uses Home Assistant test doubles and does not replace runtime or physical-device testing.

Existing support covers AC air conditioners, WD washer-dryers, DW dishwashers and RF refrigerators using the supported cloud protocol. This release does not certify additional models or account regions. New linting, dependency vulnerability scanning and dependency maintenance automation are deferred to a later release.

## Türkçe

Bu sürüm İngilizce/Türkçe arayüz desteği ekler; başlangıç hızını, komut doğrulamasını ve tanılama gizliliğini iyileştirir. Kurulum belgeleri ve kaynak atfı da güncellendi.

### Yükseltmeden önce okuyun

**Bazı otomasyon değerleri değişiyor.** Seçim seçenekleri, enum sensör durumları ve klima fan modları artık sabit makine anahtarları kullanır. Home Assistant bu anahtarları arayüzde İngilizce veya Türkçe gösterir.

| Önceki düz metin değeri | Yeni makine anahtarı |
| --- | --- |
| `Ekonomi` | `eco` |
| `Pamuklu` | `cotton` |
| `Soğutma` (enum sensörü/seçenek) | `cooling` |
| `Auto` (klima fan modu) | `auto` |

Yükseltmeden sonra otomasyonlara güvenmeden önce betik, şablon ve panellerdeki düz metin değerlerini kontrol edin. Gerçek durum/seçenek değerlerini Geliştirici Araçları'ndan alın; çevrilmiş ekran etiketlerini kopyalamayın. Geçmiş kayıtlarda eski metinler ve yeni anahtarlar birlikte bulunabilir. Gelişmiş `vestel_appliances.apply` değerleri üreticinin tam sayı kodları olarak kalır; bunların yerine makine anahtarı yazmayın.

Home Assistant yedeği alın, HACS üzerinden güncelleyin ve yeniden başlatma istemini izleyin. Mevcut `vestel_appliances` kaydını koruyun. Varlık kimlikleri ve benzersiz kimlikler korunur; özel entegrasyon kayıt adınız değiştirilmez. Varsayılan görünen ad **Vestel Smart Life** oldu.

Yeni depo [halilyildiz/vestel-smart-life-home-assistant](https://github.com/halilyildiz/vestel-smart-life-home-assistant). GitHub eski depo adresini yönlendirir; yalnızca depo adı değişti diye entegrasyon kaydını silmeyin. Asgari Home Assistant sürümü **2026.11.0** olarak kalır.

[Geçiş rehberini](https://github.com/halilyildiz/vestel-smart-life-home-assistant/blob/main/docs/upgrading.tr.md) okuyun. Mehmet Aktaş'ın `vestel_smarthome` entegrasyonundan geçiş, ayrı kurulum ve varlık bağlantılarının güncellenmesini gerektirir.

### İyileştirmeler

- Kontroller, durum etiketleri, servisler, seçim alanları ve kullanıcıya gösterilen hatalar için İngilizce/Türkçe çeviriler.
- Enerji geçmişini beklemeden başlayan cihaz kontrolleri ve canlı güncellemeler; kaldırma sırasında iptal edilen ilk arka plan sorgusu.
- Paylaşılan register'da yalnızca hedef alanların doğrulanması; UV ve iptal işlemlerinin mevcut kontrollerinin korunması.
- Geçici oturum sunucusu hataları ve istek sınırlarında gereksiz yeniden giriş istenmemesi; bozuk yanıtlar karşısında kayıtlı kimlik bilgilerinin korunması.
- Teknik alanlarla sınırlandırılmış tanılama ve iç içe/tekrarlanan hassas değerler için güçlendirilmiş maskeleme. Dosyayı paylaşmadan önce yine de inceleyin.
- Sadeleştirilmiş iki dilli README'ler; ayrı gelişmiş kullanım, geçiş, sorun giderme ve güvenlik bildirim rehberleri.
- [Mehmet Aktaş'ın orijinal MIT lisanslı projesine](https://github.com/mehmetaktas/ha-vestel-smarthome) açık atıf ve kurulum klasöründe iki tam MIT bildirimi.
- Node.js 24 çalışma ortamını kullanan checkout/setup-python eylemleri.

### Doğrulama ve kapsam

Güncel çevrimdışı kümede **155 test geçti**. GitHub Actions çevrimdışı testleri, hassfest ve HACS doğrulamasını çalıştırır. Testler çoğunlukla Home Assistant taklit sınıflarını kullanır; gerçek ortam veya fiziksel cihaz testlerinin yerini tutmaz.

Mevcut destek, uyumlu bulut protokolünü kullanan AC klima, WD kurutmalı çamaşır makinesi, DW bulaşık makinesi ve RF buzdolabını kapsar. Yeni model veya hesap bölgesi doğrulanmış sayılmaz. Yeni lint, bağımlılık güvenlik taraması ve otomatik bağımlılık bakımı sonraki sürüme bırakılmıştır.
