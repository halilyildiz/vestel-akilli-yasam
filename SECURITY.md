# Security reports

Do not post credentials, authentication tokens, device identifiers or unredacted diagnostics in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise open a non-sensitive issue asking the maintainer for a private reporting channel, without including the vulnerability details or secrets.

This integration authenticates to the existing vendor cloud account. It does not create new users or expand account permissions. Cloud access and remote appliance operations remain subject to the vendor's requirements.
